# ИИ для «Оттенка дня»: Gemini через прокси на Cloudflare

Сайт не хранит ключ. Он обращается к маленькому серверу (Cloudflare Worker),
а тот уже ходит в Google Gemini с твоим ключом. Всё бесплатно в пределах лимитов.

## 1. Получи ключ Gemini
1. Открой https://aistudio.google.com/app/apikey и войди в Google-аккаунт.
2. Нажми **Create API key** и скопируй ключ. Никому его не показывай и не клади в код сайта.

## 2. Создай прокси на Cloudflare (через сайт, без программ)
1. Зарегистрируйся на https://dash.cloudflare.com (бесплатный план).
2. **Workers & Pages → Create → Create Worker**, назови, например, `ottenok-dnya-ai`, нажми **Deploy**.
3. **Edit code**: удали всё и вставь содержимое файла `worker/worker.js`, нажми **Deploy**.
4. **Settings → Variables and Secrets**:
   - `GEMINI_API_KEY` — тип **Secret**, значение: твой ключ.
   - `ALLOWED_ORIGINS` — тип Text, адреса сайта через запятую, например
     `http://localhost:5173,https://твой-ник.github.io`.
   - (необязательно) `GEMINI_MODEL` = `gemini-3.8-flash`, `GEMINI_TTS_MODEL` = `gemini-2.5-flash-preview-tts`.
5. Скопируй адрес воркера, он выглядит как `https://ottenok-dnya-ai.<аккаунт>.workers.dev`.
6. Проверь в браузере: `https://.../health` должен вернуть `{"ok":true,...}`.

### Или через командную строку
```
cd worker
npx wrangler login
npx wrangler secret put GEMINI_API_KEY
npx wrangler deploy
```

## 3. Подключи сайт
Открой `js/config.js` и впиши адрес:
```js
export const AI_URL = 'https://ottenok-dnya-ai.<аккаунт>.workers.dev';
```
Перезагрузи сайт. В «··· → Настройки» точка ИИ станет зелёной: «ИИ подключён · Google Gemini».

## Что делает ИИ
- **При создании дня**: настроение, палитра из 3 цветов (смотрит на фото), название папки,
  деление текста на листки без изменения слов, погода внутри дня, объяснение «почему так», манера чтения.
- **«Прочитать вслух»**: эмоциональный голос Gemini TTS под настроение
  (спокойный — Sulafat, яркий — Puck, напряжённый — Kore, задумчивый — Enceladus).
  Готовое аудио сохраняется внутри дня, повторное чтение лимит не тратит.
- **Старые дни**: в меню дня пункт «Пересчитать с ИИ».

Если ИИ недоступен (нет адреса, кончился лимит, нет сети), сайт сам работает на встроенном
алгоритме и системном голосе браузера.

## Если что-то не так
- `403 origin not allowed` — добавь адрес сайта в `ALLOWED_ORIGINS`.
- `GEMINI_API_KEY is not set` — секрет не добавлен или добавлен как обычная переменная.
- Ошибка про модель — Google мог переименовать модель. Поменяй `GEMINI_MODEL` / `GEMINI_TTS_MODEL`
  на актуальные из https://ai.google.dev/gemini-api/docs/models.
- «high demand» или долгий ответ — основная модель перегружена на бесплатном тарифе. Прокси ждёт её
  12 секунд и сам переходит на запасные модели из `GEMINI_FALLBACK`
  (по умолчанию `gemini-flash-lite-latest,gemini-flash-latest`).
- `429` — сработало ограничение частоты (15 анализов и 30 озвучек в минуту с одного адреса).

## Приватность
Заметки, уменьшенные фото (до 3 штук) и название песни отправляются в Google только при
создании дня, пересчёте и озвучке. Для демо используй свои или вымышленные данные.
